**Settings → REST Filter** に設定画面があります。

## 使い方

1. テキストエリアに許可するクエリ変数を **1行1変数** で入力します
2. 「変更を保存」で `rest_filter_allowed_vars` option に保存されます

## 画面の見方

- **現状**: option が保存されている場合は「option で上書き中」、未設定なら「デフォルト（upstream 互換）」と表示されます
- **危険変数の警告**: `post_status`、`perm`、`has_password`、`meta_*` を含めると警告が出ます。これらは匿名 API 利用者に非公開データや高コストクエリを許す可能性があるため、意図的な場合だけ含めてください
- **空入力は拒否**: 全部消して保存しても反映されず、前回値が保持されます

## 初期値

初回表示時は現在有効な変数リスト（デフォルト or 保存済み option）が入っています。`lang` のようなプラグイン追加変数も含まれます（`query_vars` フィルタ適用後のリストで計算するため）。

## 投稿タイプのスコープ

ページ下部の「filter を有効にする投稿タイプ」で、`filter` を受け付けるタイプをチェックボックスで選べます。

- チェックしたタイプだけで `filter` が有効になります
- **全部外して保存** → 全タイプで `filter` 無効（保存された空配列として記録）
- **「すべての投稿タイプに適用」にチェック** → option を削除してデフォルト（全タイプ）に戻します
